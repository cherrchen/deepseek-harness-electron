# plans/ — Large implementation plans

Holds **large, multi-commit implementation tasks**: goals, approach, task lists, and verification records.

- Plans in progress live in [`active/`](active/README.md); once done and verified they **move to** [`completed/`](completed/README.md) — never deleted, because plans are part of project history.
- Nothing lingers in active; small tasks do not deserve a plan and are reflected directly in the matching canonical document.
- Skeleton: [`.agent/templates/plan.md`](../../.agent/templates/plan.md).
